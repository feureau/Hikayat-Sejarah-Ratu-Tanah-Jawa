## [Folio 78]

1: żurriyyatê Adam iku kabèh teka ing ‘ālam żurriyyat iku
2: marang ing ‘ālam donya iku maka winiwitan
3: iku dedalan loro ing donya iku dalan kang
4: marang ing suwarga dalan kang marang ing naraka
5: maka dalan kang marang ing suwarga iku dalan
6: kang padhang dalan kang marang ing naraka iku
7: dalan kang peteng déné dalan kang padhang
8: iku dalan marang ing kamulyan dalan kang
9: peteng iku dalan marang ing kanisṭan
10: déné dalan kang padhang iku dalané para
11: Nabī para walī para mukmin kang pada
12: olèh pitulungé Robbil ‘ālamīn maka
[catchword: agung tegesé iya iku mulihé marang ing suwarga]

## [Folio 79]

1: ing dedalan loro iku marang kang holadan kang marang
2: ing naraka iku dalané para kāfir para
3: munāfiq para fāsiq para zindīq kang pada
4: katutupan atiné marang Iblīs la‘natullāh
5: maka dadi nisṭa tegesé iya iku mulihé
6: marang ing naraka jahanam maka lamun wus
7: tito mangkono iku poma-poma sira kabèh
8: pada amiliha marang dalan kang padhang iku
9: tegesé dalan kang padhang iku dalaning agama
10: Islam karsané Gusti Allāh subḥānahu wa-ta‘ālā
11: kang ‘azza wa-jalla kang wāḥidu ’l-qahhār
12: marma dadi wajib sira kabèh anglampahana
[catchword: -jalla kang wāḥidu ’l-qahhār marang ing sarupané]
